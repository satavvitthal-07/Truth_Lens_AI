Before you upload

  • Only JPG, JPEG and PNG are accepted.
  • Images are sent to the configured Flask backend for screening.
  • Successfully analyzed media is retained locally until you delete its history record or an administrator removes it.
  • Analysis history stores metadata and results in SQLite; original image files are stored separately.
Do not upload sensitive, private, or personally identifying images. Local storage is not a backup service. A model result is an indicator, not proof.
What to expect

If a suitable model has not been configured, TruthLens will report that detection is unavailable. It does not generate placeholder predictions.
